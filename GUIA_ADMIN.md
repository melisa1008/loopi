## Uso desde Windows o teléfono

No se necesita Linux ni usar comandos.

### Moderar una historia

1. Abre Loopi Admin (`/admin/`) e inicia sesión con el correo de administradora.
2. En **Pendientes**, lee el envío y usa **Corregir**, **Publicar**, **Rechazar** o **Eliminar**.
3. Las historias publicadas aparecen dentro de Loopi, sin Google Forms ni GitHub.

## Aplicaciones en el teléfono

- La aplicación normal de Loopi abre la web para lectores. El envío de historias lleva al formulario de Google.
- Para administrar, abre `/admin/` y usa **Instalar aplicación**. Se llamará **Loopi Admin**.

## Si parece que la página no se actualiza

Abre el enlace con una recarga completa o cierra y vuelve a abrir la aplicación. La web ya no guarda contenido antiguo intencionadamente.
